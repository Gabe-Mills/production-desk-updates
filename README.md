# Production Desk
This is a tool I vibe coded for myself to use on a couple of productions. I'm not a professional software designer but I do want to share this with the world so it can be improved and others can use it. I'll do my best to support it and hopefully it helps others as it did me. 
# The Features? 
I wanted a offline, self hosted solution for doing script breakdowns and creating schedules. The shot list functionality was added it at the request of a friend. I hope to continue to develop it FOR FREE and allow people to have a easier time making productions themselves! 
# Mac update
Production Desk 1.4.2 removes the nonfunctional account-linking and online transfer controls. Settings provides Light and Dark appearance. Projects, breakdowns, schedules, shots, and file exports stay local. Open Production Desk and use **Production Desk → Check for Updates…** to install the latest version.

# iPhone and iPad
The offline iOS app source is in [`ios/`](ios/README.md). Open `ios/ProductionDesk.xcodeproj` in Xcode and run the `ProductionDesk` scheme on an iOS 17 or later simulator. It preserves the Production Desk brand and local breakdown, schedule, shot list, elements and report workflows. See the [setup guide](ios/README.md), [iOS installer](ios/INSTALL.md) and [verification notes](ios/VERIFICATION.md) for build commands, file interchange and device signing requirements.
